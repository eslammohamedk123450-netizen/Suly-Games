# Suly City

لعبة مدينة Three.js إيزومترية 2.5D، في نسختها التأسيسية: خريطة عشبية شبكية، كاميرا متعامدة قابلة للسحب، ومبنى بسيط يُوضَع بالنقر أو اللمس. جميع أشكال المبنى مصنوعة برمجيًا من مجسمات Three.js بدائية؛ لا صور أو خامات أو نماذج خارجية.

## التشغيل

```bash
pnpm install
pnpm dev
```

افتح عنوان Vite المحلي الذي يظهر في الطرفية. للبناء الإنتاجي والاختبارات:

```bash
pnpm build
pnpm test
pnpm smoke
```

يشغّل `pnpm smoke` بعد البناء فحصًا آليًا للكاميرا والأرض والإضاءة والظلال ووضع المباني بالسحب واللمس على الكمبيوتر والهاتف، ويحفظ لقطات الاختبار في `shots/`.

## التحكم

- النقر أو اللمس على الأرض يضع مبنى متمركزًا على أقرب خلية في الشبكة.
- سحب الماوس أو الإصبع يحرك الكاميرا فوق الخريطة.

## تفاصيل التنفيذ

المشهد يستخدم `OrthographicCamera` بزاوية إيزومترية ثابتة، وأرضية `PlaneGeometry` بمقاس 100×100، و`GridHelper`، وإضاءة محيطية واتجاهية مع ظلال `PCFSoftShadowMap`. نقطة ارتكاز المبنى في أسفل منتصفه عند `Y=0`. يعرض التطبيق المشهد فقط، بلا قوائم أو HUD أو منطق لعب إضافي.

حُدّث مسار العرض ليستخدم WebGLRenderer بخيار `antialias` و`high-performance`، ويُقيّد كثافة البكسل إلى `Math.min(devicePixelRatio, 2)` للهواتف. حزمة الإنتاج لا تحمل ملفات الخطوط أو خامات ونماذج اللعب.

المشروع مبني على Vite وTypeScript مع Three.js. لا يتضمن هذا الإصدار إعدادًا لتغليف APK أصلي؛ إنه أساس الويب الخفيف القابل للتوسعة لاحقًا.
