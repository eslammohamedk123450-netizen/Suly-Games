# Suly City

لعبة مدينة Three.js إيزومترية 2.5D على خريطة عشبية شبكية. تُبنى الطرق والمباني من مجسمات بدائية مولدة برمجيًا، دون صور أو خامات أو نماذج GLTF خارجية.

## التشغيل

```bash
pnpm install
pnpm dev
```

افتح عنوان Vite المحلي الذي يظهر في الطرفية. للبناء الإنتاجي والاختبارات:

```bash
pnpm build
pnpm test
pnpm smoke
```

يشغّل `pnpm smoke` بعد البناء فحصًا آليًا للكاميرا والأرض والإضاءة والظلال، ووضع الطرق والمباني وشرط التجاور، والسحب والتكبير على الكمبيوتر والهاتف. تحفظ لقطات الاختبار في `shots/`.

## التحكم

- يبدأ اللعب في وضع الطريق؛ انقر أو المس خلية فارغة لإضافة قطعة طريق.
- استخدم زر الوضع الظاهر على الشاشة، أو `R` لوضع الطريق و`B` لوضع المباني.
- لا يُسمح ببناء مبنى إلا في خلية فارغة تشارك ضلعًا مع طريق موجود.
- اسحب بإصبع واحد أو بالماوس لتحريك الكاميرا؛ يستمر التحريك قليلًا بقصور مخمّد بعد رفع الإصبع.
- قرّب أو أبعد بإصبعين على الهاتف، أو بعجلة الفأرة على الكمبيوتر.
- يبيّن المربع الأخضر إمكانية الوضع، والأحمر يبيّن الخلية المشغولة أو المبنى غير المتصل بطريق.

## تفاصيل التنفيذ

المشهد يستخدم `OrthographicCamera` بزاوية إيزومترية ثابتة، وأرضية `PlaneGeometry` بمقاس 100×100، و`GridHelper`، وإضاءة محيطية واتجاهية مع ظلال `PCFSoftShadowMap`. كل خلية 2×2؛ مركزها يُحسب بواسطة `Raycaster` و`Math.round` على إحداثيي X وZ. تُصنع الطرق والمباني من مجسمات Three.js بدائية، وأصل المبنى في أسفل منتصفه عند `Y=0`.

يستخدم العرض `WebGLRenderer` بخياري `antialias` و`high-performance`، ويُقيّد كثافة البكسل إلى `Math.min(devicePixelRatio, 2)` للهواتف. حزمة اللعب لا تتضمن صورًا أو خامات أو نماذج خارجية.

المشروع مبني على Vite وThree.js. لا يتضمن إعدادًا لتغليف APK أصلي؛ إنه أساس ويب خفيف قابل للتوسعة لاحقًا.
