# Suly City

لعبة مدينة Three.js إيزومترية 2.5D على الخريطة الشبكية الحالية. تُعرض المباني بصور PNG شفافة مأخوذة من أصول `public/`، وتُبنى قطع الطرق من مجسمات Three.js.

## التشغيل

```bash
pnpm install
pnpm dev
```

افتح عنوان Vite المحلي الذي يظهر في الطرفية. للبناء الإنتاجي والاختبارات:

```bash
pnpm build
pnpm test
pnpm smoke
```

يشغّل `pnpm smoke` بعد البناء فحصًا آليًا للكاميرا والأرض والإضاءة والظلال، ووضع الطرق والمباني وشرط التجاور، والسحب والتكبير على الكمبيوتر والهاتف. تحفظ لقطات الاختبار في `shots/`.

## التحكم

- يبدأ اللعب في وضع الطريق؛ انقر أو المس خلية فارغة لإضافة قطعة طريق.
- اختر `Road` أو `House` أو `Shop` أو `Skyscraper` من شريط الأدوات السفلي؛ ويمكن استخدام `R` و`H` و`S` و`K` على لوحة المفاتيح.
- لا يُسمح ببناء مبنى إلا في خلية فارغة تشارك ضلعًا مع طريق موجود.
- اسحب بإصبع واحد أو بالماوس لتحريك الكاميرا؛ يستمر التحريك قليلًا بقصور مخمّد بعد رفع الإصبع.
- قرّب أو أبعد بإصبعين على الهاتف، أو بعجلة الفأرة على الكمبيوتر.
- يبيّن المربع الأخضر إمكانية الوضع، والأحمر يبيّن الخلية المشغولة أو المبنى غير المتصل بطريق.

## تفاصيل التنفيذ

المشهد يستخدم `OrthographicCamera` بزاوية إيزومترية ثابتة، وأرضية `PlaneGeometry` بمقاس 100×100، و`GridHelper`، وإضاءة محيطية واتجاهية مع ظلال `PCFSoftShadowMap`. كل خلية 2×2؛ مركزها يُحسب بواسطة `Raycaster` و`Math.round` على إحداثيي X وZ. تُحمّل صور المباني الشفافة من `public/assets/` كخامات `PlaneGeometry` ذات محور عند الحافة السفلية وارتفاع Y=0؛ لا ترمي ظلالًا مربعة. يُعاد ترتيب صور المباني حسب موقعها الرأسي على الشاشة كل إطار.

يستخدم العرض `WebGLRenderer` بخياري `antialias` و`high-performance`، ويُقيّد كثافة البكسل إلى `Math.min(devicePixelRatio, 2)` للهواتف. نسخ sprites المقصوصة والمخفّضة من الأصول الأصلية تحفظ الشفافية وتحد من استهلاك النقل والذاكرة.

المشروع مبني على Vite وThree.js. لا يتضمن إعدادًا لتغليف APK أصلي؛ إنه أساس ويب خفيف قابل للتوسعة لاحقًا.
